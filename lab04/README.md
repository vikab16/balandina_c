Вопросы:

1. Что такое файл в языке C

Файл в языке C — это последовательность байтов, хранящаяся на диске или другом носителе, с которой программа может взаимодействовать через потоки ввода-вывода. Файл может содержать текст, числа, структуры или любые другие данные. В C файл рассматривается как поток данных, к которому программа получает доступ через файловый указатель.

2. Что такое FILE*
FILE* (файловый указатель) — это указатель на структуру типа FILE, которая определена в <stdio.h>. Эта структура содержит информацию о файле: буфер, текущую позицию чтения/записи, индикаторы ошибок и конца файла, режим открытия. Через этот указатель выполняются все операции с файлом.

3. Какие режимы открытия файла существуют

"r"	    Чтение текстового файла (файл должен существовать)
"w"	    Запись текстового файла (создаётся новый или перезаписывается существующий)
"a"	    Добавление в конец текстового файла
"rb"    Чтение бинарного файла
"wb"	Запись бинарного файла
"ab"	Добавление в конец бинарного файла
"r+"	Чтение и запись текстового файла
"w+"	Чтение и запись (создание или перезапись)
"a+"	Чтение и добавление в конец
"rb+"	Чтение и запись бинарного файла
"wb+"	Чтение и запись бинарного (перезапись)
"ab+"	Чтение и добавление в конец бинарного

4. Чем отличается текстовый файл от бинарного

putc(символ, файловый_указатель)
Записывает один символ в файл
Возвращает записанный символ или EOF при ошибке

5. Что делают функции putc и getc
getc(файловый_указатель)
Считывает один символ из файла
Возвращает прочитанный символ или EOF при достижении конца файла или ошибке

6. Что делают fgets и fputs

fputs(строка, файловый_указатель)
Записывает строку в файл (без автоматического добавления \n)
Возвращает неотрицательное число при успехе, EOF при ошибке

fgets(буфер, размер, файловый_указатель)
Читает строку из файла, включая символ \n, но не более размер-1 символов
Возвращает указатель на буфер при успехе, NULL при ошибке или конце файла

7. Что делают fprintf и fscanf

fprintf(файл, формат, переменные)
Форматированная запись данных в файл (аналог printf для файла)
Возвращает количество записанных символов или отрицательное число при ошибке

fscanf(файл, формат, &переменные.)
Форматированное чтение данных из файла (аналог scanf для файла)
Возвращает количество успешно считанных элементов или EOF при ошибке/конце файла

8. Что делают fread и fwrite

fwrite(данные, размер_элемента, количество, файл)
Бинарная запись данных в файл
Возвращает количество полностью записанных элементов

fread(буфер, размер_элемента, количество, файл)
Бинарное чтение данных из файла
Возвращает количество полностью прочитанных элементов

9. Что делают fseek и ftell

fseek(файл, смещение, откуда)
Перемещает указатель позиции в файле

ftell(файл)
Возвращает текущую позицию файлового указателя (в байтах от начала)

10. Что делают feof и ferror

feof(файл)
Проверяет, достигнут ли конец файла
Возвращает ненулевое значение, если конец файла достигнут, иначе 0
Становится истинным только после попытки чтения за концом файла

ferror(файл)
Проверяет, произошла ли ошибка ввода-вывода
Возвращает ненулевое значение при ошибке, иначе 0

11. Почему важно закрывать файл ответь на вопросы

Причины важности закрытия файла:
Освобождение ресурсов — каждый открытый файл занимает память и дескриптор в ОС (их количество ограничено)
Сохранение данных — при записи данные могут находиться в буфере; fclose() вызывает сброс буфера (fflush)
Предотвращение потери данных — при аварийном завершении программы несохранённые буферы могут быть потеряны
Доступ для других программ — закрытый файл может быть открыт другими процессами
Корректное повторное открытие — нельзя переименовать, удалить или изменить режим открытого файла
